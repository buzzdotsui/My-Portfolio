
# MASTER PORTFOLIO ARCHITECTURE

## Testimony Owolabi

### The central idea

The site is a **professional portfolio + body-of-work archive**.

Not a résumé.

Not a personal blog.

Not a startup landing page.

Not a “developer showcase.”

The page should make one thing increasingly obvious as someone scrolls:

> **Testimony knows how to build things, think about systems, work across disciplines, lead people, and create useful outcomes.**

Everything else proves that.

# Why I think this is finally the right architecture

Because it retains the **professional density and page logic** that makes the reference strong, without turning your portfolio into a clone in terms of content.

It also solves the problem the previous architecture couldn't solve:

### A software recruiter sees:

**Work → Skills → Experience → CV**

### An AI recruiter sees:

**Craft → AI work → Skills → Projects**

### A Web3 recruiter sees:

**Work → Web3 → Sui → Leadership → Evidence**

### An engineering recruiter sees:

**Identity → Engineering → Academic evidence → Metabotics → Industrial projects**

### A leadership evaluator sees:

**Experience → Leadership → Sui On Campus → 17 real photographs**

### A client sees:

**Work → Services → Availability → Contact**

### A collaborator sees:

**Metabotics → Writing → Now → Contact**

And yet **none of these are separate websites**.

It's one coherent professional system.
